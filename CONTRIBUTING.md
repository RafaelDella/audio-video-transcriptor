# Como contribuir

Obrigado pelo interesse em melhorar o Transcreve Local.

1. Crie um fork e uma branch para a mudança.
2. Instale o projeto com `python -m pip install -e ".[dev]"`.
3. Faça mudanças pequenas e inclua testes quando aplicável.
4. Execute `pytest` e `ruff check .`.
5. Abra um pull request explicando o problema e a solução.

Não inclua áudios, transcrições, modelos ou informações pessoais nos commits.
Para relatar uma falha, informe sistema operacional, versão do Python, comando
executado e mensagem de erro. Use arquivos artificiais ou anonimizados.
